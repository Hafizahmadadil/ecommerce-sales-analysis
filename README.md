# 📊 E-commerce Sales Data Analysis

## 🔍 Overview

This project analyzes e-commerce sales data to extract business insights.

---

## 📁 Project Structure

* data/ → dataset
* src/ → Python analysis script

---

## 📊 Key Insights

* Top revenue category identified
* Best performing region analyzed
* Correlation between ad spend and revenue

---

## ⚙️ Tools Used

* Python
* Pandas
* Matplotlib

---

## 🚀 How to Run

```bash
pip install -r requirements.txt
python src/analysis.py
```
